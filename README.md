## Reflection

One key difference between relational databases like MySQL and non-relational/document databases like MongoDB is that relational databases require a fixed schema, while MongoDB collections support flexible, dynamic documents that can have varied structures. Another difference is that SQL databases use tables and relationships, whereas MongoDB organizes data as JSON-like documents, making it easier to represent complex, nested data.

In healthcare, MongoDB could be ideal for storing and managing Electronic Health Records (EHRs), where each patient’s data is diverse and may change over time (e.g., allergies, procedures, notes). The flexible schema of MongoDB enables healthcare organizations to efficiently manage varied and evolving datasets without frequent migrations or redesigns.
